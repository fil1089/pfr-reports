🚀 Стратегия: Ежемесячный сбор групп + привлечение в Сенлер

🎯 Задача

  • Автоматизировать ежемесячный сбор целевых сообществ по смежным нишам (психология, психосоматика, ПТСР, тревожность)
  • Создать систему привлечения подписчиков в Сенлер через таргет, виджеты и контент

⚠️ ВАЖНО: Как работает Сенлер

Сенлер ≠ рекламный кабинет VK!

В Сенлер нельзя просто загрузить список VK User ID и начать им писать. Это запрещено правилами VK и технически невозможно.

Как человек попадает в базу Сенлер:

  • Сам пишет в сообщество (нажимает «Написать сообщество»)
  • Подписывается через виджет/кнопку в группе
  • Кликает на рекламу с переходом в бот
  • Участвует в розыгрыше/квизе через Сенлер

Итого: человек должен сам разрешить сообщения от сообщества. Только после этого ему можно отправлять рассылки.

📅 ЧАСТЬ 1: Ежемесячный сбор целевых групп

Зачем собирать группы?

Целевые группы нужны не для загрузки в Сенлер (это невозможно), а для:

  • Таргетированной рекламы — загружаем аудиторию в рекламный кабинет VK как похожую аудиторию (Lookalike)
  • Анализа конкурентов — изучаем их контент, форматы, хуки
  • Поиска площадок для размещений — договариваемся о кросс-постах и рекламных интеграциях

Ротация тем (3-месячный цикл)

Месяц 1 — Широкая воронка (низкая осознанность):

  • Психосоматика (psychosomatics)
  • Тревожность (anxiety)
  • Панические атаки (panic_attacks)
  • Бессонница (insomnia)
  • Хроническая усталость (chronic_fatigue)

Месяц 2 — Средняя воронка (ищут решение):

  • Психологи онлайн (psychologists_online)
  • Телесная терапия (somatic_therapy)
  • Работа с травмой (trauma_therapy)
  • ПТСР (ptsd)
  • ДПДГ / EMDR (emdr_therapy)

Месяц 3 — Узкая воронка (знают методы):

  • ПФР (pfr_method)
  • Билатеральная стимуляция (bilateral_stimulation)
  • Нейропсихология (neuropsychology)
  • Фасциальная терапия (fascial_therapy)
  • Психотерапия выгорания (burnout_therapy)

Автоматизация через планировщик

Запускай 1-го числа каждого месяца (вручную или через cron/Task Scheduler):

Пример для темы "психосоматика"

python 09_vk_bot/scripts/vk_harvester.py --topic "психосоматика" --output 09_vk_bot/data/harvested_psychosomatics.json
python 09_vk_bot/scripts/jev_filter.py --input 09_vk_bot/data/harvested_psychosomatics.json --topic "психосоматика" --output-json 09_vk_bot/data/clean_psychosomatics_communities.json --output-txt 09_vk_bot/data/clean_psychosomatics_ids.txt
python 09_vk_bot/scripts/report_hub.py --dataset 09_vk_bot/data/clean_psychosomatics_communities.json --slug psychosomatics --title "🎯 База: психосоматика" --badge "Психосоматика"

Результат: веб-отчёт с чистой базой групп → https://fil1089.github.io/pfr-reports/

📥 ЧАСТЬ 2: Как привлекать людей в Сенлер (ПРАВИЛЬНО)

Стратегия №1: Таргетированная реклама VK → Бот Сенлер

Схема:

  • Собираешь активную аудиторию из целевых групп (через audience_collector.py)
  • Загружаешь её в рекламный кабинет VK (не в Сенлер!) как базу для Lookalike
  • Настраиваешь рекламу с кнопкой «Написать сообщение» → переход в бот Сенлер
  • Человек кликает → пишет боту → автоматически попадает в базу Сенлер

Как собрать аудиторию для рекламы:

Выгружаем активных пользователей (лайки/комментарии за 30 дней)

python 09_vk_bot/scripts/audience_collector.py --targets-file 09_vk_bot/data/clean_psychosomatics_ids.txt --mode active

Результат: файл с VK User ID → загружаешь в рекламный кабинет VK → создаёшь Lookalike 1% (похожая аудитория).

Креатив рекламы:

  • Хук: «Устала, зажата, болит? Врачи ничего не находят?»
  • Оффер: «Пройди тест за 2 минуты — узнай, откуда напряжение»
  • Кнопка: «Написать сообщение» → запускается бот-квиз в Сенлер
  • Результат: человек проходит квиз → получает разбор → попадает в базу Сенлер

Стратегия №2: Виджет в группе VK

Устанавливаешь виджет Сенлер на главной странице группы psiholog_firsov:

Текст виджета: 

🎁 Бесплатный чек-лист: 5 признаков, что тело держит застрявшую эмоцию
👉 Нажми «Получить» — пришлю в личные сообщения

Кнопка: «Получить чек-лист» → человек кликает → разрешает сообщения → попадает в базу Сенлер

Настройка: Сенлер → Виджеты → Создать виджет для VK → Выбрать группу → Вставить текст и кнопку.

Стратегия №3: Кнопка действия в группе

В группе psiholog_firsov рядом с кнопкой «Подписаться» можно добавить кнопку действия:

Текст кнопки: «Пройти тест»

Действие: Открыть бот Сенлер с квизом

Настройка: Управление сообществом → Настройки → Кнопка действия → Открыть приложение → Вставить ссылку на бот Сенлер.

Стратегия №4: Лид-магнит в постах

Каждые 7–10 дней публикуешь пост с лид-магнитом:

Пример поста: 

Три ночь не сплю. Ночью просыпаюсь в 3 часа — и всё, до утра лежу с открытыми глазами.
Врач говорит: «Стресс. Попейте валерьянку». Но валерьянка не работает.
Потому что дело не в нервах. Дело в том, что тело держит незавершённую реакцию. Нервная система застряла в режиме «бей/беги» — и не может переключиться на сон.
Я записал короткий разбор (5 минут): откуда берётся такая бессонница и что с ней делать.
📩 Напиши мне «бессонница» в личные сообщения — пришлю ссылку.

Человек пишет «бессонница» → бот Сенлер автоматически отвечает и отправляет материал → человек в базе.

Стратегия №5: Квиз-бот на входе

Создаёшь в Сенлер квиз (5–7 вопросов):

Тема: «Тест: откуда у тебя хроническое напряжение?»

Вопросы:

  • Как часто просыпаешься ночью? (варианты)
  • Болит ли спина/шея без видимой причины? (да/нет)
  • Сложно расслабиться даже в отпуске? (да/нет)
  • Чувствуешь, что «сжалась внутри»? (да/нет)
  • Пробовала разговорную терапию — не помогло? (да/нет)

Результат: «Судя по ответам, твоя нервная система в режиме выживания. Вот 3 признака застрявшего спазма + что с этим делать: [ссылка на статью]»

Призыв: «Хочешь разобраться глубже? Запишись на разбор с психологом → [кнопка]»

Квиз распространяешь через:

  • Таргет VK (кнопка «Пройти тест»)
  • Посты в группе (ссылка на квиз)
  • Истории VK (свайп вверх → квиз)

📊 ЧАСТЬ 4: Метрики и контроль

Что отслеживать в Сенлер:

  • Прирост базы — сколько новых подписчиков в месяц (цель: 200–500)
  • Open Rate — % открывших рассылку (норма: 30–50% для прогретой базы)
  • CTR — % кликов по кнопкам (норма: 5–15%)
  • Конверсия в запись — цель 2–5% от базы за 30 дней

Что отслеживать в рекламном кабинете VK:

  • CPM (цена 1000 показов) — норма для психологов: 50–150 руб
  • CTR рекламы — норма: 0.5–2%
  • CPC (цена клика) — норма: 5–20 руб
  • Цена подписчика — цель: 30–100 руб за человека в боте

python 09_vk_bot/scripts/audience_collector.py --targets-file 09_vk_bot/data/clean_target_ids.txt --mode active

Результат: файл active_audience_YYYY-MM-DD.txt → загружаешь в рекламный кабинет VK.

Шаг 3: Настрой виджет в группе VK

  • Открой Сенлер → Виджеты → Создать виджет
  • Текст: «🎁 Бесплатный чек-лист: 5 признаков застрявшего напряжения»
  • Кнопка: «Получить» → отправляет PDF в бот
  • Установи виджет на главной странице группы psiholog_firsov

  • Сенлер → Процессы → Создать процесс
  • Триггер: «Новый подписчик»
  • Добавь 5 писем из примера выше с паузами (0 дней, 1 день, 3 дня, 5 дней, 7 дней)
  • Настрой кнопки с переходом в сегменты («Тёплые», «Горячие»)

Шаг 5: Запусти первую рекламу VK

  • Загрузи активную аудиторию в кабинет VK → создай Lookalike 1%
  • Креатив: «Устала, зажата, болит? Пройди тест за 2 минуты»
  • Кнопка: «Написать сообщение» → запуск квиз-бота Сенлер
  • Бюджет: 500–1000 руб/день на старте

💡 Главный инсайт

Сенлер — это НЕ инструмент для "заливки" чужих баз.

Сенлер — это инструмент для автоматизации общения с теми, кто сам разрешил тебе писать.

Схема работы:

  • Собираешь целевые группы → анализируешь контент + берёшь аудиторию для Lookalike в рекламе
  • Запускаешь рекламу VK / виджеты / лид-магниты в постах → люди сами пишут в бот
  • Бот автоматически добавляет их в базу Сенлер → запускается welcome-цепочка
  • Прогреваешь через контент → конвертируешь в консультации / марафоны

Никаких "загрузить 10 000 VK ID и начать спамить". Только честный прогрев через ценность.
